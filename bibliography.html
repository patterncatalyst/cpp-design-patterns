Bibliography

The reference books behind this book.

This book is a runnable, opinionated reference that points at a small set of excellent books rather than displacing them. Every citation in the chapters is a pointer, something like "see Feathers ch. 9 for the full technique," not a substitute for reading the source. These are books we recommend, not books we wrote; nothing here copies them. If a title is useful to you, please go read it in full.

Anniversary edition; the source for Brooks's Law in the programming-principles appendix.		 Frederick P. Brooks Jr. Addison-Wesley 1995 Software engineering / process

Citation discipline

Every citation in this book is a pointer, something like "see Fowler ch. 6 for the full catalogue entry," not a displacing summary. The books exist; if this book replaced reading them, it would do the authors and the reader a disservice.
