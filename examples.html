Example demos

Runnable companions to the book.

Every pattern chapter has a demo behind it. Each demo is a self-contained, standalone-buildable CMake project with its own Conan recipe and a GoogleTest suite run through CTest — no containers. Read the matching chapter for context, then build the demo from its directory with the same local tools the prerequisites chapter installs.

Runnable examples

Each example makes a single pattern concrete and runnable with one command. Every card links to the demo's page on this site (a rendering of the README with cross-references), and each page links to the source on GitHub. Each demo also stands alone, so you can build it without reading the book first if you'd rather poke at it directly.

Building every demo

Clone the repo and build each example from its directory with the pinned local toolchain (clang, CMake, Ninja, Conan 2.x — see the prerequisites chapter and scripts/check-prereqs.sh). 

git clone https://github.com/{{ site.github_username }}/{{ site.github_repo }}.git
cd {{ site.github_repo }}
./scripts/build.sh
./scripts/verify.sh cpp23

Every example is also standalone-buildable from its own directory with conan install and cmake --preset cpp23, without configuring the whole repo.
