{%- comment -%} Multi-language code tabs. Emits an empty marker; assets/js/codetabs.js absorbs the next N fenced code blocks (N = number of pipe-separated labels) into an accessible tab group. Because the code blocks stay ordinary Markdown fences, Rouge still highlights them at build time — no plugin required. Usage (place the marker, then one fenced block per label, IN THIS ORDER): {% raw %}{% include codetabs.html langs="C++20|C++23" %}{% endraw %} ```cpp // C++20 ``` ```cpp // C++23 ``` This book standardizes on exactly two standards tabs, C++20 and C++23. C++26 is deferred (see Appendix A) and must not appear in a `langs=` list. Selecting a tab syncs every group on the page and is remembered across pages. {%- endcomment -%}
